# Brief — Handheld Bag

*[OddWire](../../../../../README.md) › [Survival](../../.git.md) › Handheld Bag*

**Scope:** Vanilla Patch
**Domain:** OddWire.Survival
**Status:** Active

---

## What it is
A set of Harmony patches that let a small bag (under 4 slots, e.g. a basket) be carried in the hotbar and filled directly — by right-clicking blocks to pick up drops, and by merging items onto it in the inventory — trading a tool-holding slot for a little extra carry.

---

## Core Loop

```
Hold a small bag in the hotbar → right-click blocks (drops route into the bag, then inventory, then ground) → or merge items onto the bag in the inventory
```

---

## Gameplay Loop

| Input | Action | Reward | Risk |
|---|---|---|---|
| Small bag (< 4 slots) in active hotbar slot | right-click a block to pick it up | drops fill the bag first, overflow to inventory/ground | a tool slot is occupied by the bag |
| Item onto the bag in the inventory | click to merge | the item moves into the bag's slots | a bag already sitting in a bag-content slot swaps instead of merging |

---

## Class Responsibility

| Class | Owns |
|---|---|
| `IHeldBag_Extensions` | `IsHandheld` — identifies small bags by slot count |
| `BBRightClickPickup_BasketIntercept_Patch` | routes right-click block pickup into the held bag |
| `CollectibleObject_GetMergableQuantity / TryMergeStacks_Patch` | accept + perform the item→bag direct-merge |
| `ItemSlot_ActivateSlotLeftClick_Patch` | forces swap when a bag sits in a bag-content slot |
| `ItemSlotSurvival_CanHold / CanTakeFrom_Patch` | permit filled small bags in survival slots |
