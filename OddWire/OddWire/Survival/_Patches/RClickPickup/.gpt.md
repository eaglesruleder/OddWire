# Doc — Handheld Bag

**Scope:** Subsystem
**Domain:** oddwire
**Status:** Active

---

## Summary

**Goal:** Allows small IHeldBag items (< 4 slots) to be carried in the hotbar and receive items via inventory merge and right-click block pickup.

**Lifecycle:**
1. Player holds small bag in active hotbar slot
2. Right-click a block — drops route into bag slots first, overflow to inventory or ground
3. Open inventory — click item onto bag to merge into bag slots
4. If bag is sitting in a bag content slot — click forces swap instead of merge

**Rules:**
- Only bags with < 4 slots are treated as handheld — large backpacks are excluded
- Merge into bag is DirectMerge only — AutoMerge falls through to base
- Bag in ItemSlotBagContent always swaps, never merges
- Server performs all mutations — client calculates MovedQuantity only
- CanTakeFrom and CanHold pass through to base for ItemSlotBagContent — never short-circuit

**State:** `Stored: bag slot contents via IHeldBag.Store() — Derived: none — Persisted: via bag itemstack attributes`

---

## Implementation

### IHeldBag_Extensions
IsHandheld helper — identifies small bags by slot count threshold.

```
IsHandheld(bag, stack)
  // Intent: < 4 slots targets basket; simplest viable discriminator
  return GetQuantitySlots < 4
```

### BBRightClickPickup_BasketIntercept_Patch
Intercepts right-click block pickup when a handheld bag is active.

```
Prefix()
  #region if(!bag.IsHandheld) return true
  #region client: PreventDefault, return false
  #region dropStacks = dropsPickupMode ? GetDrops() : OnPickBlock()
  #region foreach dropStack — fill bag slots, overflow to inventory or spawn
  #region SetBlock(0), TriggerNeighbourUpdate
```

### CollectibleObject_GetMergableQuantity_HeldBagAcceptsItems_Patch
Signals handheld bag as a valid DirectMerge target.

```
Prefix()
  #region if(!DirectMerge || !bag.IsHandheld) return true
  #region result = sourceStack.StackSize
```

### CollectibleObject_TryMergeStacks_HeldBagAcceptsItems_Patch
Performs item→bag slot merge on DirectMerge; both sides share one loop.

```
Prefix()
  #region if(SinkSlot is ItemSlotBagContent || !bag.IsHandheld) return true
  #region foreach slot — CanHold gate, fill empty or stack-match
  // Intent: server writes, client only tracks remaining for MovedQuantity
  #region moved > 0 — set MovedQuantity, server: deduct source, MarkDirty
```

### ItemSlot_ActivateSlotLeftClick_SwapBagInSlotBag_Patch
Forces TryFlipWith when a handheld bag occupies a bag content slot.

```
Prefix()
  #region if(!ItemSlotBagContent || !bag) return true
  #region TryFlipWith(sourceSlot)
```

### ItemSlotSurvival_CanHold_AllowSmallBag_Patch
Permits filled small bags to be held in survival slots.

```
Prefix()
  #region if(ItemSlotBagContent) return true (base)
  #region if(!IsHandheld filled bag) return true (base)
  #region result = Inventory.CanContain
```

### ItemSlotSurvival_CanTakeFrom_AllowSmallBag_Patch
Permits taking filled small bags from survival slots.

```
Prefix()
  #region if(ItemSlotBagContent) return true (base)
  // Intent: return true not false — false skips original and returns default false
  #region if(!IsHandheld filled bag) return true (base)
  #region result = true
```
