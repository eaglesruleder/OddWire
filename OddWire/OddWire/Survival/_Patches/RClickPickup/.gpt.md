# Doc — Small Bag Patches

**Scope:** Vanilla Patch
**Domain:** OddWire.Survival
**Status:** Active

---

## Summary

**Goal:** Allow bags with fewer than 4 slots (`IHeldBag.GetQuantitySlots < 4`) to sit in survival inventory slots and to receive right-click block pickups — behaviours vanilla restricts to larger bags or no bags.

**Lifecycle:**
1. Player holds a small bag and right-clicks a pickup block — `BBRightClickPickup` prefix intercepts, routes drops into the bag, falls back to inventory then world spawn
2. Player moves a small bag into a survival slot — `CanHold` prefix allows it via `Inventory.CanContain`
3. Player takes a small bag from a survival slot — `CanTakeFrom` prefix always allows it

**Rules:**
- "Small bag" gate throughout: `IHeldBag != null && GetQuantitySlots < 4` — empty bags and large bags (≥ 4 slots) always fall through to vanilla
- Bag-in-bag is blocked: `CanHold` returns false immediately when `__instance is ItemSlotBagContent`
- Client side of `BBRightClickPickup` fakes success (result=true, PreventDefault) without running pickup — server is authoritative
- Bag slot acceptance requires exact stack match by `Equals(IgnoredStackAttributes)` with room, or an empty slot — matched stacks increment `StackSize` directly
- If bag is full and `TryGiveItemstack` fails, item spawns at block position

**State:** `None stored — stateless intercepts; bag content state managed by IHeldBag.Store`

---

## Implementation

### BBRightClickPickup_BasketIntercept_Patch  *(Prefix)*
Intercepts right-click block pickup when the active hotbar item is a small bag. Routes drops into bag slots, with inventory and world-spawn fallback.

```
Prefix(world, byPlayer, blockSel, ref handling, ref __result, __instance) → bool
  #region if(!bag || bag.QtySlots >= 4) return true
  #region if(client) __result=true; handling=PreventDefault; return false  — server authoritative
  #region dropStacks = dropsPickupMode ? block.GetDrops() : [block.OnPickBlock()]
  #region slots = bag.GetOrCreateSlots(bagstack, ...)
  #region foreach(dropStack)
    #region if(bagSlots.Any(empty || matching+room)) bagSlot.Add + bag.Store + MarkDirty
    #region if(!accepted) TryGiveItemstack || SpawnItemEntity
  #region SetBlock(0, pos) + TriggerNeighbourBlockUpdate
  #region __result=true; handling=PreventDefault; return false
```
`// Intent: StackSize++ used for matched slots — guard (StackSize < MaxStackSize) prevents overflow`  
`// Intent: dropsPickupMode read via Traverse from private field on __instance`

---

### ItemSlotSurvival_CanHold_AllowSmallBag_Patch  *(Prefix)*
Allows small bags to be held in survival slots via `Inventory.CanContain`; blocks bag-in-bag.

```
Prefix(sourceSlot, ref __result, __instance) → bool
  #region if(bag.IsEmpty) return true  — vanilla handles empty bags
  #region if(__instance is ItemSlotBagContent) return false  — no bag-in-bag
  #region if(quantitySlots >= 4) return true  — vanilla handles large bags
  #region __result = __instance.Inventory.CanContain(__instance, sourceSlot); return false
```

---

### ItemSlotSurvival_CanTakeFrom_AllowSmallBag_Patch  *(Prefix)*
Allows small bags to always be taken from survival slots.

```
Prefix(sourceSlot, ref __result) → bool
  #region if(bag.IsEmpty || quantitySlots >= 4) return true
  #region __result = true; return false
```
