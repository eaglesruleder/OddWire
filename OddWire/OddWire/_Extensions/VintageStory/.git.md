*[OddWire](../../../../README.md) › [Extensions](../.git.md) › VintageStory API · Code: [VintageStory/.gpt.md](.gpt.md)*

**Scope:** Subsystem
**Domain:** OddWire
**Status:** Active

---

## What it is
Reusable extension helpers over the Vintage Story API: environment sampling (climate, rainfall, sky/greenhouse), item/block stack resolution, shape/transform/tesselation caching, and TreeAttribute (de)serialization for engine property types.

---

## What it provides

| Helper | Provides |
|---|---|
| EnvironmentSystemExtensions | sky exposure, climate-at-hours, rainfall-over-a-span, greenhouse-aware temperature |
| ItemStackExtensions | `CanBurn`, and code → `ItemStack` resolution (`ResolveStack` / `ResolveStacks`) |
| ITesselatorAPIExtensions | cached shape tesselation with root-element limiting |
| ShapeExtensions / ModelTransformExtensions | shape path/folder normalisation; transform → stable cache key |
| CombustiblePropertiesExtensions / GroundStoragePropertiesExtensions | partial TreeAttribute round-trip for those engine property types |

---

## Consumed by
CompostPile — environment temperature, rainfall, and sky/greenhouse detection, plus stack resolution for its interaction help. Available to any feature needing the same engine glue.
