# Doc — VintageStory API Extensions

**Scope:** Subsystem
**Domain:** OddWire (engine glue)
**Status:** Active

---

## Summary

**Goal:** Reusable extension helpers over the Vintage Story API — environment sampling, item/block stack resolution, shape/transform/tesselation helpers, and `ITreeAttribute` (de)serialization for engine property types.

**Rules:**
- Namespaces mirror the folder under `OddWire.VintageStory.*` — except `EnvironmentSystemExtensions`, which sits in `OddWire.GameContent` (outlier).
- Property (de)serializers (`Combustible*`, `GroundStorage*`) write only non-default scalar fields; stack/box/sound/model fields are intentionally skipped (commented out) — round-trip is partial by design.
- Cache keys for tesselation compose `path + transform.ToKey() + #qtyRootElements`; `qtyRootElements` counts root elements *including* their nested children.

**State:** `Stateless — all static helpers; only engine-side caches via ObjectCacheUtil`

**Consumed by:** CompostPile (env temp / rainfall / sky-greenhouse, and stack resolution for interaction help); available to any feature needing engine glue.

---

## Implementation

### EnvironmentSystemExtensions  (namespace `OddWire.GameContent`)
Climate, rainfall, sky-exposure, and greenhouse-aware temperature sampling.

```
IsSkyExposed(blockAccessor, pos)  — GetRainMapHeightAt(x,z) <= pos.Y

GetClimateAtHours(world, pos, totalHours)  — GetClimateAt(ForSuppliedDate_TemperatureRainfallOnly, totalHours / HoursPerDay)

GetTotalRainfallSince(weather, pos, fromHours, toHours)
  // Intent: integrate precipitation over an arbitrary span by adaptive sampling — coarser granularity for longer spans (year > month > day > hour) to bound iteration count
  #region if(to <= from) return 0
  #region loop remainingDays: pick sample duration by span, sample WorldGenValues climate, accumulate GetPrecipitation x duration

GetEnvironmentTemperatureC(api, pos, totalHours, skyExposed, greenhouseTempBonusC, out inGreenhouse)
  #region temp = GetClimateAtHours().Temperature
  #region if(!skyExposed and room is skylit & exitless) → inGreenhouse, temp += greenhouseTempBonusC
```

### ItemStackExtensions  (`OddWire.VintageStory.API.Common`)
```
CanBurn(stack, reqStackSize = true)  — CombustibleProps.BurnTemperature > 0 (and StackSize > 0 unless reqStackSize is false)
ResolveStack(api, code)   — GetItem else GetBlock → ItemStack; null if neither resolves
ResolveStacks(api, codes) — resolve each, skip nulls
```

### ITesselatorAPIExtensions  (`OddWire.VintageStory.API.Client`)
```
CacheTesselateShape(..., mesher, ...)  — cache-tesselate then AddMeshData to the mesher
CacheTesselateShape(..., out meshdata, ...)
  // Intent: qtyRootElements limits render to N *root* elements, each counted with all its nested children — not N flat elements
  #region meshKey = path + transform.ToKey() + #qtyRootElements; return cached if present
  #region Shape.TryGet(path.json); else return false
  #region renderElements = sum over first N roots of (1 + CountElementChildren)
  #region TesselateShape, apply transform, cache, return

CountElementChildren(children)  — recursive count of all nested child elements
```
