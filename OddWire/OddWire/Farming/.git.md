## What it is
The organic-farming domain: a tick-driven composting simulation plus the watering interaction that feeds it, built on a shared `IWaterable` hook so moisture is delivered by the base-game watering can rather than a custom tool.

---

## Features

| Feature | What it is | Brief | Doc |
|---|---|---|---|
| CompostPile | A two-stage decomposition block — browns + nutrition + inoculum convert to compost over time, gated by temperature, moisture, aeration, and an inoculum culture | [.git.md](CompostPile/.git.md) | [.gpt.md](CompostPile/.gpt.md) |
| WateringCan Patch | Harmony patch on the vanilla watering can — dispatches elapsed watering time to any `IWaterable` block at the target position | — | [.gpt.md](_Patches/WateringCan/.gpt.md) |

`IWaterable` is the domain's shared contract: the WateringCan patch is the producer, CompostPile is the first consumer. New moisture-driven blocks implement `IWaterable` to receive watering for free.

---

## Class Responsibility

| Class | Owns |
|---|---|
| `BlockEntityCompostpile` | pile state, environment sim, input acceptance, two-stage processing, harvest, ticking, heat/tint, persistence |
| `BlockCompostpile` | player interaction, interaction help, neighbour-change signalling, break → harvest routing |
| `CompostpileSettings` | all CompostPile tuning + per-ingredient and per-food-category data |
| `BlockWateringCan_..._IWaterable_Patch` | postfix on the vanilla watering can — captures `dt` and dispatches to `IWaterable` |
| `IWaterable` | domain contract — a block that accepts elapsed watering time via `Water(dt)` |
| `OddWireFarming` | ModSystem — registers the CompostPile block and block-entity classes |
