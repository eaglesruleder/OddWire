# Doc — CompostPile

**Scope:** Feature  
**Domain:** OddWire.Farming  
**Status:** Active

---

## Summary

**Goal:** Converts organic inputs into compost over time via a tick-driven simulation of moisture, aeration, temperature, and stress — driven by input balance and environmental conditions.

**Lifecycle:**
1. Craft from rot + drygrass, place block
2. Fill inputs — browns (drygrass), inoculum (rot/compost), nutrition (food items)
3. Maintain moisture — water manually or rely on rainfall if sky-exposed
4. Wait — simulation ticks every 12s, progressing moisture / aeration / temperature / stress
5. Harvest — break with shovel; drops compost, compostpile blocks, browns, inoculum
6. Turn — add any input to restore aeration; blocked neighbours accelerate aeration decay

**Rules:**
- Output room checked before any mutation
- Progression stalls if no inoculum/compost OR no browns/nutrition
- Nutrition is lossy — not recovered on harvest
- Compost and inoculum share the same slot pool (MaxQty 64 combined)
- Aeration decays faster when pile is full or neighbours block airflow
- Creative shape variants #1–#5 driven by TotalQty, stacked per 64

**State:**
`Stored: BrownsQty, NutritionStacks[FoodCategory], InoculumQty, CompostQty, Moisture01, Temperature, Aeration01, Stress01, AdjacentBlockCount, AdjacentBlockHeat, PrevTime* timestamps — Derived: Factor, Health01, Insulation01, EnvTemp — Persisted: all stored state via TreeAttribute`

## Implementation

### BlockCompostpile
Handles player interaction, neighbour notifications, and break/harvest routing.

```
OnBlockInteractStart()
  — require compostpile BE, require held stack
  — call be.TryAdd; reject if not accepted
  — server only: slot.TakeOut(accepted), slot.MarkDirty

OnHeldInteractStart()
  #region require non-shift compostpile target
  #region consume held input before default block placement
  #region fall through to base placement

OnNeighbourBlockChange()
  — flag be.NeighboursDirty on server

OnBlockBroken()
  #region require compostpile BE and server-side break authority
  — be.Harvest(dropQuantityMultiplier)
  — if be.CanHarvest(): return (pile still has contents, block stays)
  — base.OnBlockBroken (removes emptied block)
```

### BlockEntityCompostpile
Owns all pile state, environment simulation, input acceptance, processing, harvest, tick scheduling, heat emission, tint rendering, and persistence.

```
// #region IHeatSource

GetHeatStrength()
  // Intent: quadratic curve — heat scales sharply above 35C and with pile fullness
  #region require temperature above 35C
  #region return quadratic heat scaled by fullness


// #region IBlockTint

RegenTintMesh()  — client only; tessellates and uploads current block mesh for tinting
DisposeTintRenderer()  — disposes tint renderer and mesh ref
OnTesselation()  — returns true; suppresses default tessellation, tint renderer draws instead
OnExchanged()  — regens tint mesh on client when block variant changes


// #region State

TotalQty / GetFullness01()  — derived from Browns + Nutrition + Inoculum + Compost


// #region Rate Factors & Failure Stress

GetFactor()
  // Intent: returns 0 if no inoculum/compost OR no browns/nutrition — hard stall conditions
  — require (inoculum > 0 || compost > 0) AND (browns > 0 || nutrition > 0); else return 0
  — return NutritionFactor x InoculumFactor x TemperatureFactor x MoistureFactor

GetInoculumFactor01()
  // Intent: Compost counts toward factor so efficiency doesn't crash as inoculum converts
  — (inoculum + compost) / MaxQty, clamped 0.1–1.0

GetHealth01()   — AerationHealth x TemperatureHealth x MoistureHealth
GetStress01()   — 1 - GetHealth01()

GetMoistureStress01()
  // Intent: anaerobic01 squared relaxes drowning penalty — aerated wet piles tolerate moisture better
  — drowning risk gated by (1 - aeration01)^2

GetNutritionFactor()   — weighted sum of NutritionStacks by NutritionSpeed / MaxQty
GetTemperatureFactor01() / GetTemperatureStress01()  — piecewise curve; 20–55C optimal
GetMoistureFactor01() / GetMoistureStress01()  — curve with drowning penalty above threshold
GetAerationHealth01() / GetAerationStress01()  — linear ramp below HypoxicThreshold


// #region Interaction

SetShapeStackSize()
  #region resolve target size variant from TotalQty (ceiling per 64, clamped 1–5)
  #region exchange block variant on server if changed

TryAdd()
  #region delegate to TryAddIngredient
  #region update shape stack size and mark dirty

CanHarvest()
  // Intent: Nutrition is lossy — NutritionQty excluded from harvest check
  — return CompostQty > 0 || InoculumQty > 0 || BrownsQty > 0

Harvest()
  // Intent: | not || — both compost and compostpile harvest paths must always evaluate
  #region harvest compost, then compostpile bundles
  #region harvest browns and inoculum only if no compost/pile drops
  #region update shape and mark dirty


// #region Harvest

HarvestCompost / HarvestCompostpile / HarvestBrowns / HarvestInoculum
  — shared pattern:
  #region require qty > 0 and resolvable spawn item/block
  #region spawn randomised stacks up to harvest qty limit
  #region reduce stored qty, update insulation

GetHarvestableCompostpileQty()
  — min(browns, nutrition, inoculum) each divided by their InitialQty

ResetOnPlaced()
  #region resolve placed stack size variant bonus
  #region apply initial browns / nutrition / inoculum quantities by stack bonus
  #region reset all dynamic state and timestamps


// #region TryAdd

TryAddIngredient()  — internal dispatch; called from TryAdd
  #region require input stack
  #region resolve accepted add path — compostpile > browns > inoculum > nutrition
  #region apply aeration restore and update insulation

TryAddRef()  — browns and inoculum path
  #region require registered item code ratios, ingredient room, and input stack
  #region resolve input code and conversion ratio
  #region resolve accepted input and output quantities
  #region apply accepted quantities

TryAddCompostPile()  — stacked compostpile block as bundled input
  // Intent: Nutrition is lossy — matching harvest behaviour; nutrition overflow is not dropped
  #region require compostpile stack with valid size variant
  #region resolve bundled ingredient quantities by stack bonus
  #region require recoverable ingredient room
  #region resolve and apply accepted per-ingredient quantities
  #region drop recoverable bundled overflow (browns and inoculum only)

TryAddNutrition()  — food item input
  #region require nutrition props and nutrition room budget
  #region resolve nutrition per input via GetNutritionPerInput
  #region resolve consumable input qty and nutrition output qty
  #region apply nutrition gain to NutritionStacks by food category

GetNutritionPerInput()  — resolves effective nutrition value from perish transition chain
  #region require transitionable props
  #region find Perish transition matching inoculum item code ratios
  #region return transitionRatio x inoculumRatio, or 1 if no match


// #region TryRemove

TryRemoveCheapestNutrition()  — harvest and compostpile transition consumption
  #region loop: find cheapest category by NutritionSpeed weight, remove until amount met

TryRemoveRandomNutrition()  — processing consumption
  // Intent: removal chance scales per category's share of nutritionRemaining
  #region loop: pick random category weighted by stack size, remove until amount met


// #region Lifecycle

Initialize()
  #region recover legacy unset moisture state
  #region start client-side tint renderer and regen mesh
  #region flag NeighboursDirty, start server-side 12s tick listener

OnBlockPlaced()
  #region reset state via ResetOnPlaced
  #region seed PrevTimeProcessed, flag NeighboursDirty, update shape

OnBlockRemoved() / OnBlockUnloaded()  — dispose tint renderer


// #region NeighbourSamplingAndTickUpdate

OnEvery12Seconds()
  #region require server side
  #region refresh neighbour airflow and heat state if dirty
  #region sample GetNeighbourHeat into AdjacentBlockHeat
  #region advance simulation via Update, update shape if dirty

GetNeighbourHeat()
  #region require _neighbourHeatSource flag
  #region loop faces (skip DOWN), accumulate IHeatSource.GetHeatStrength per face

UpdateNeighbourBlocks()
  #region count blocked airflow faces (UP, N, S, E, W)
  #region flag _neighbourHeatSource from adjacent IHeatSource blocks

BlocksAirflow()
  #region require non-null neighbour block
  #region flag adjacent heat interface
  #region treat adjacent compostpile as airflow blocker
  #region ignore replaceable blocks
  #region return solid or collision-box neighbour as blocking

Water()  — IWaterable handler
  — require server side
  — if RestoreMoisture01(dt): MarkDirty


// #region StateUpdates

RestoreAeration01()
  #region sync aeration timestamp via UpdateAeration
  #region clamp and apply aeration boost

RestoreMoisture01()
  // Intent: gain scaled by (1 - fullness01) — fuller pile absorbs less water
  #region run PreUpdateState and UpdateMoisture to current time
  #region require moisture below cap
  #region apply moisture gain scaled by water rate and fullness

Update()
  // Intent: | not || — both UpdateState and ProcessCompost must always run and both return values captured
  #region require fully loaded chunk
  #region run UpdateState and ProcessCompost

PreUpdateState()
  #region resolve sky exposure change; force recalc if exposure changed
  #region reuse cached environment if fresh (within 1 hour)
  #region refresh env temp, greenhouse flag, insulation

UpdateInsulation01()
  — 0.25 + 0.75 * fullness01, +0.10 if indoors, +0.05 if greenhouse, clamped 0–1

UpdateState()
  — PreUpdateState (env cache refresh)
  // Intent: | not || — all four must always run regardless of individual return values
  — return UpdateMoisture | UpdateAeration | UpdateTemperature | UpdateStress

UpdateMoisture()
  #region initialise or guard timestamp
  #region collect rainfall exposure hours if sky-exposed
  #region apply rainfall gain and ambient drying scaled by envTemp
  #region clamp by passive insulation retention floor

UpdateAeration()
  #region initialise or guard timestamp
  #region apply decay scaled by fullness compaction and neighbour airflow penalty

GetInternalHeat()  — biological heat contribution to temperature target
  // Intent: aeration approaches zero → heat approaches zero; hypoxic piles stop self-heating
  #region sum nutrition heat by food category weight
  #region scale by moisture / inoculum / temperature / aeration / insulation factors

UpdateTemperature()
  #region initialise or guard timestamp; seed temperature from envTemp on first run
  #region resolve evaporative cooling and insulation cooling rate
  #region move toward target (envTemp + GetInternalHeat + AdjacentBlockHeat) via asymptotic coolingFactor

UpdateStress()
  #region initialise or guard timestamp
  #region lerp Stress01 toward GetStress01 target at gain/recovery rate


// #region Processing

ProcessCompost()
  #region reject if inoculum pool full and net-positive OR no bulk portions OR no transitions
  #region resolve available bulk portions (browns + nutrition)
  #region resolve completed transitions at rate = BaseRate x Factor
  #region resolve output split via ResolveOutputTransitions
  #region resolve consumed input portions via ResolveInputPortions
  #region apply input consumption (browns, random nutrition) and output mutation (compost, inoculum)
  #region advance PrevTimeProcessed by completed transition time

ResolveOutputTransitions()  — stress-splits transitions into compost/failed, clamps all to output room
  — ClampFailedToOutputRoom: excess failed overflows to compost
  — ClampCompostToOutputRoom: excess compost overflows to failed
  — BootstrapCompostWithFailed: subsidises compost from failed when inoculum is insufficient
  — ClampFailedToFinalRoom: final room check after bootstrap

ResolveInputPortions()  — proportional browns/nutrition split within transition budget
  #region resolve min/max browns range from available portions
  #region weight toward proportional mean, clamp to valid range

GetVisualTintRgba()
  — RGB tint from browns/nutrition/inoculum fullness, darkened by moisture and aeration


// #region Persistence

FromTreeAttributes / ToTreeAttributes
  — delegate all stored state to ReadState / WriteState under "_inventory" key

WriteState / ReadState  — private; serialize all stored state fields to TreeAttribute under keyed prefix
```

### CompostpileSettings
Static tuning data only — no runtime logic.
Defines per-ingredient (Browns, Nutrition, Inoculum) quantities, conversion ratios, and harvest yields.
Regions: IngredientTuning, CompostRate, Moisture, Aeration, Temperature, Stress, Harvest, BlockInfo.
