# Doc — CompostPile

**Scope:** Feature  
**Domain:** OddWire.Farming  
**Status:** Active

---

## Summary

**Goal:** Converts organic inputs into compost over time via a tick-driven simulation of moisture, aeration, temperature, and stress — driven by input balance and environmental conditions.

**Lifecycle:**
1. Craft from rot + drygrass, place block
2. Fill inputs — browns (drygrass), inoculum (rot/compost), nutrition (food items)
3. Maintain moisture — water manually or rely on rainfall if sky-exposed
4. Wait — simulation ticks every 12s, progressing moisture / aeration / temperature / stress
5. Harvest — break with shovel; drops compost, compostpile blocks, browns, inoculum
6. Turn — add any input to restore aeration; blocked neighbours accelerate aeration decay

**Rules:**
- Output room checked before any mutation
- Progression stalls if no inoculum/compost OR no browns/nutrition
- Nutrition is lossy — not recovered on harvest
- Compost and inoculum share the same slot pool (MaxQty 64 combined)
- Aeration decays faster when pile is full or neighbours block airflow
- Creative shape variants #1–#5 driven by TotalQty, stacked per 64

**State:**
`Stored: BrownsQty, NutritionStacks[FoodCategory], InoculumQty, CompostQty, Moisture01, Temperature, Aeration01, Stress01, AdjacentBlockCount, AdjacentBlockHeat, PrevTime* timestamps — Derived: Factor, Health01, Insulation01, EnvTemp — Persisted: all stored state via TreeAttribute`


### CompostpileInventory
Owns all stored state, environment sampling, simulation update, input acceptance, processing, and harvest.

```
// #region InputAndPlacementHandling

ResetOnPlaced()
  #region resolve placed stack size variant bonus
  #region apply initial browns / nutrition / inoculum quantities by stack bonus
  #region reset all dynamic state and timestamps

TryAdd()
  #region require input stack
  #region resolve accepted add path — compostpile > browns > inoculum > nutrition
  #region apply aeration restore and update insulation

TryAddRef()  — browns and inoculum path
  #region require registered item code ratios
  #region require ingredient room and input stack
  #region resolve input code
  #region resolve conversion ratio
  #region resolve accepted input and output quantities
  #region apply accepted quantities

TryAddCompostPile()  — stacked compostpile block as bundled input
  #region require compostpile stack with valid size variant
  #region resolve bundled ingredient quantities by stack bonus
  #region require recoverable ingredient room (nutrition is lossy)
  #region resolve accepted per-ingredient quantities
  #region apply accepted ingredients
  #region drop recoverable bundled overflow

TryAddNutrition()  — food item input
  #region require nutrition props
  #region require nutrition room budget
  #region resolve nutrition per input (via perish transition ratio)
  #region resolve consumable input qty
  #region resolve nutrition output qty
  #region apply nutrition gain to NutritionStacks by food category
  #region return consumed qty


// #region StateUpdates

RestoreAeration01()
  #region sync aeration timestamp via UpdateAeration
  #region clamp and apply aeration boost

RestoreMoisture01()
  // Intent: gain scaled by (1 - fullness01) — fuller pile absorbs less water
  #region run PreUpdateState and UpdateMoisture to current time
  #region require moisture below cap
  #region apply moisture gain scaled by water rate and fullness
  #region update timestamp

Update()
  // Intent: | not || — both UpdateState and ProcessCompost must always run
  #region require fully loaded chunk
  #region run UpdateState and ProcessCompost

PreUpdateState()
  #region resolve sky exposure change
  #region reuse fresh cached environment if recent
  #region refresh env temp, insulation, greenhouse flag

UpdateState()
  #region chain UpdateMoisture / UpdateAeration / UpdateTemperature / UpdateStress

UpdateMoisture()
  #region initialise or guard timestamp
  #region resolve elapsed days
  #region collect rainfall exposure if sky-exposed
  #region apply rainfall gain and ambient drying
  #region clamp by passive insulation retention

UpdateAeration()
  #region initialise or guard timestamp
  #region resolve elapsed days
  #region apply decay scaled by fullness compaction and neighbour airflow penalty

UpdateTemperature()
  #region initialise or guard timestamp
  #region resolve elapsed hours
  #region resolve evaporative cooling and insulation cooling response
  #region move toward target (envTemp + internal heat + neighbour heat)

GetInternalHeat()  — biological heat contribution to temperature target
  // Intent: zero aeration approaches zero heat — hypoxic piles stop heating
  #region sum nutrition heat by food category weight
  #region scale by moisture / inoculum / temperature / aeration / insulation factors

UpdateStress()
  #region initialise or guard timestamp
  #region resolve elapsed days
  #region lerp Stress01 toward health-derived target at gain/recovery rate


// #region Processing

ProcessCompost()
  #region initialise or reject processing window
  #region resolve available bulk portions (browns + nutrition)
  #region resolve completed transitions at rate = BaseRate x Factor
  #region resolve output split (compost vs failed) via ResolveOutputTransitions
  #region resolve consumed input portions via ResolveInputPortions
  #region apply input consumption and output mutation
  #region advance PrevTimeProcessed

ResolveOutputTransitions()  — stress-splits transitions into compost/failed, clamps to output room
  #region split by Stress01 into compost and failedOutput
  #region clamp failed to inoculum room, overflow to compost
  #region clamp compost to net output room, overflow to failed
  #region bootstrap compost with failed when inoculum is insufficient
  #region clamp failed to final room

ResolveInputPortions()  — proportional browns/nutrition split within transition budget
  #region resolve min/max browns range
  #region weight toward proportional mean, clamp to valid range
  #region return browns and nutrition portions


// #region HarvestRecoveryAndLoss

HarvestCompost / HarvestCompostpile / HarvestBrowns / HarvestInoculum
  — shared pattern:
  #region require qty > 0 and resolvable spawn item/block
  #region spawn randomised stacks up to harvest qty limit
  #region reduce stored qty, update insulation


// #region NutritionConsumptionOrder

TryRemoveCheapestNutrition()  — harvest and compostpile transition consumption
  #region loop: find cheapest category by NutritionSpeed weight, remove until amount met

TryRemoveRandomNutrition()  — processing consumption
  #region loop: pick random category weighted by stack size, remove until amount met


// #region RateAndStressHelpers

GetFactor()    — NutritionFactor x InoculumFactor x TemperatureFactor x MoistureFactor
GetHealth01()  — AerationHealth x TemperatureHealth x MoistureHealth
GetNutritionFactor()   — weighted sum of NutritionStacks by NutritionSpeed / MaxQty
GetMoistureStress01()  — drowning risk gated by anaerobic state (1 - aeration01) squared
GetInoculumFactor01()  — (inoculum + compost) / MaxQty, clamped 0.1-1.0


// #region Visuals

GetVisualTintRgba()
  — RGB tint from browns/nutrition/inoculum fullness, darkened by moisture and aeration


// #region Persistence

ToTreeAttributes / FromTreeAttributes
  — serialize all stored state fields to TreeAttribute under keyed prefix
```

### CompostpileSettings
Static tuning data only — no runtime logic.
Defines per-ingredient (Browns, Nutrition, Inoculum) quantities, conversion ratios, and harvest yields.
Defines rate, moisture, aeration, temperature, stress, and output tuning constants.
