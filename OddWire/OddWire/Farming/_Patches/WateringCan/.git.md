# Brief — WateringCan Patch

*[OddWire](../../../../../README.md) › [Farming](../../.git.md) › WateringCan Patch*

**Scope:** Vanilla Patch
**Domain:** OddWire.Farming
**Status:** Active

---

## What it is
A Harmony patch on the base-game watering can that forwards the time spent watering to any block implementing `IWaterable` — so modded blocks receive watering through the vanilla tool instead of needing a custom one.

---

## Core Loop

```
Hold watering can → water a block → elapsed time (dt) dispatched to the target's IWaterable.Water(dt)
```

The target resolves down through empty and fluid faces, so watering the ground or a water surface reaches the block beneath. Server-side only.

---

## Gameplay Loop

| Input | Action | Reward | Risk |
|---|---|---|---|
| Watering can over an `IWaterable` block | hold-water as normal | the block gains moisture proportional to watering time | none — refill ticks are ignored, so topping the can up doesn't double-count |

---

## Class Responsibility

| Class | Owns |
|---|---|
| `BlockWateringCan_OnHeldInteractStep_IWaterable_Patch` | postfix on the vanilla watering can — captures `dt` and dispatches it to the resolved `IWaterable` |
| `IWaterable` | the Farming contract — a block that accepts elapsed watering time via `Water(dt)` |
