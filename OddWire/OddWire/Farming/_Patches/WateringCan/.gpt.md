# Doc — WateringCan Waterable Patch

**Scope:** Vanilla Patch
**Domain:** OddWire.Farming
**Status:** Active

---

## Summary

**Goal:** Intercepts base-game watering can interact steps to dispatch elapsed time (dt) to any `IWaterable` block at the target position.

**Lifecycle:**
1. Player holds watering can and interacts with a block
2. Prefix captures pre-step `secondsUsed` as `__state`
3. Base-game `OnHeldInteractStep` runs
4. Postfix computes dt, validates result, side, and slot — skips refill ticks
5. Resolves target block position — steps through empty and fluid layers
6. Dispatches `Water(dt)` to block if it implements `IWaterable`

**Rules:**
- Only dispatches on server side
- dt must be positive — zero or negative dt is skipped
- Refill ticks are skipped — `refilled > 0` guard must not be removed
- Target position resolves down one if selected face has no collision boxes and no fluid block
- `Water()` is only called when the resolved block implements `IWaterable`

**State:** `None — dt derived per call from secondsUsed delta`

## Implementation

### BlockWateringCan_OnHeldInteractStep_IWaterable_Patch
Harmony postfix patch on `BlockWateringCan.OnHeldInteractStep` — captures dt and dispatches to IWaterable.
