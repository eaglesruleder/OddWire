# Doc — Plowland Patches

**Scope:** Vanilla Patch
**Domain:** OddWire.Farming
**Status:** Active

---

## Summary

**Goal:** Hook plowland into vanilla `BlockCrop`, `ItemPlantableSeed`, and `BlockEntitySoilNutrition` lifecycle events without forking those classes — using `ICropland` and `IWaterable` as the seam.

**Lifecycle:**
1. Seed planted — `ItemPlantableSeed.OnHeldInteractStart` prefix intercepts plowland target, calls `ICropland.TryPlant`
2. Crop validates placement — `BlockCrop.IsNotOnFarmland` postfix overrides rejection when block below is `ICropland`
3. Crop interacted — `BlockCrop.OnBlockInteractStart` prefix routes fertiliser/etc through `BESN.OnBlockInteract`
4. Crop broken — `BlockCrop.OnBlockBroken` postfix calls `BESN.OnCropBlockBroken` to reset farmland state
5. Crop drops — `BlockCrop.GetDrops` prefix delegates to `ICropland.GetDrops` with vanilla base drops as input
6. Water spreads — `BESN.WaterFarmland` postfix propagates moisture to adjacent `IWaterable` blocks when `waterNeighbours=true`
7. Crop renders — `BlockCrop.AdjustYPosition` postfix applies farmland vertical offset when below is `BlockPlowland`

**Rules:**
- Every patch that touches vanilla farmland behaviour guards `besn/target is not BlockEntityFarmland` — vanilla handles its own, patches handle the rest
- `GetDrops` sets `SplitDropStacks = false` before invoking base — required so drops pass through as a single stack for `ICropland.GetDrops` to modify
- `WaterFarmland` postfix only fires when `waterNeighbours=true`; propagated amount is `dt / 3f` (not full dt)
- `AdjustYPosition` postfix only fires if `__result == 0f` — vanilla already handled a non-zero offset
- `OnLoaded` deduplication guard checks for an existing `BlockPlowland` stack before appending — safe to re-run

**State:** `None stored — all patches are stateless intercepts`

---

## Implementation

### ICropland
Seam interface. Defines the contract patches call into; implementations live in `BlockEntityPlowland` (and partly in `BlockEntitySoilNutrition` base).

```
TryPlant(cropBlock, itemslot, byEntity, blockSel) → bool
GetDrops(drops[]) → ItemStack[]
OnCropBlockBroken()     // base implementation in BlockEntitySoilNutrition
OnBlockInteract(byPlayer) → bool  // base implementation in BlockEntitySoilNutrition
```

### BlockCrop_patch.cs

#### BlockCrop_IsNotOnFarmland_OrIsICropland_Patch  *(Postfix)*
```
Postfix(world, pos, ref __result)
  #region if(!__result) return  — vanilla already approved, nothing to do
  #region if(blockEntity(pos.Down) is ICropland) __result = false  — override rejection
```

#### BlockCrop_OnBlockInteractStart_CallsBESN_Patch  *(Prefix)*
```
Prefix(world, byPlayer, blockSel, ref __result) → bool
  #region if(blockEntity(pos.Down) is not BESN || is BlockEntityFarmland) return true
  #region if(besn.OnBlockInteract(byPlayer)) __result = true; return false
```

#### BlockCrop_OnBlockBroken_CallsBESN_Patch  *(Postfix)*
```
Postfix(world, pos, byPlayer, dropQuantityMultiplier)
  #region if(blockEntity(pos.Down) is not BESN || is BlockEntityFarmland) return
  #region besn.OnCropBlockBroken()
```

#### BlockCrop_GetDrops_CallsICropland_Patch  *(Prefix)*
```
Prefix(__instance, world, pos, byPlayer, dropQuantityMultiplier, ref __result) → bool
  #region if(blockEntity(pos.Down) is not ICropland || is BlockEntityFarmland) return true
  #region __instance.SplitDropStacks = false  — must precede base invoke
  #region baseDrops = Block.GetDrops(...) via reflection
  #region __result = cropland.GetDrops(baseDrops); return false
```
`// Intent: SplitDropStacks=false so base returns a single merged stack; ICropland.GetDrops receives it whole`

#### BlockCrop_GetPlacedBlockInfo_CallsBlockPlowland_Patch  *(Prefix)*
```
Prefix(world, pos, forPlayer, ref __result) → bool
  #region if(block(pos.Down) is not BlockPlowland) return true
  #region __result = downBlock.GetPlacedBlockInfo(world, pos.Down, forPlayer); return false
```

#### BlockCrop_AdjustYPosition_Patch  *(Postfix)*
```
Postfix(__instance, pos, chunkExtBlocks, extIndex3d, ref __result)
  #region if(__result != 0f) return  — vanilla handled
  #region if(block below is BlockPlowland) __result = onFarmlandVerticalOffset (via reflection)
```

### BlockEntitySoilNutrition_patch.cs

#### BlockEntitySoilNutrition_WaterFarmland_Patch  *(Postfix)*
Propagates moisture from irrigation source to adjacent plowland when the vanilla call includes neighbour watering.

```
Postfix(__instance, dt, waterNeighbours)
  #region if(!waterNeighbours) return
  #region foreach(HORIZONTALS) GetInterface<IWaterable>(npos)?.Water(dt / 3f)
```
`// Intent: dt/3f — adjacent blocks receive a third of the source irrigation pulse`

### ItemPlantableSeed_patch.cs

#### ItemPlantableSeed_OnHeldInteractStart_PlantICropland_Patch  *(Prefix)*
Intercepts seed planting when target block entity is `ICropland`. Runs full plant-and-consume flow then short-circuits vanilla.

```
Prefix(__instance, itemslot, byEntity, blockSel, ..., ref handHandling) → bool
  #region if(!blockSel || blockEntity(blockSel.pos) is not ICropland || is BlockEntityFarmland) return true
  #region croptype = Variant["type"]; if(null) return false
  #region cropBlock = GetBlock("crop-{croptype}-1"); if(null) return false
  #region if(!target.TryPlant(cropBlock, itemslot, byEntity, blockSel)) return false
  #region PlaySoundAt("sounds/block/plant") + TriggerFpAnimation
  #region if(!Creative) itemslot.TakeOut(1) + MarkDirty
  #region handHandling = PreventDefault; return false
```

#### ItemPlantableSeed_OnLoaded_Patch  *(Postfix)*
Client-side only. Appends plowland block stacks to the seed's interaction tooltip so the player sees valid placement targets.

```
Postfix(__instance, api)
  #region if(!client) return
  #region interactions = field("interactions").GetValue(__instance); if(null/empty) return
  #region if(interactions[0] already contains BlockPlowland stack) return  — dedup guard
  #region extra = all blocks where EntityClass resolves to BlockEntityPlowland
  #region if(extra.Count == 0) return
  #region interactions[0].Itemstacks = merged(existing + extra)
```
`// Intent: dedup guard checks block type not count — safe to re-run across hot-reloads`
