## Summary

**Goal:** Converts soil into high-retention farmland that sustains moisture and NPK long enough to complete more harvests per season — yield advantage comes from faster crop cycling, not increased drops.

**Lifecycle:**
1. Hold plow, right-click soil/farmland/plowland — drag-plows once held past `PlowSecondsRequired`
2. `DoPlow` rolls a fertility step, places `plowland-{side}-{moist}-{fertility}`, transfers nutrients
3. Perpendicular neighbours revert to farmland — plowland stays a 1-wide furrow along facing
4. Plant + grow — vanilla `GetGrowthRate` combines NPK + moisture into a per-tick growth multiplier
5. NPK drains — stage advancement pulls nutrients, shared proportionally with adjacent uncropped soil
6. Moisture decays — rate driven by `totalHoursWaterRetention`, set from the support block's fertility
7. Re-plow — `Initialise()` resets nutrients and moisture in place without destroying crop data

**Rules:**
- `UpdateSupport()` must precede the vanilla base interval / `tryUpdateMoistureLevel` — it sets `totalHoursWaterRetention` first
- `DoPlow` aborts if `targetFertilityCode` is null or the plowland block does not resolve
- Nutrient distribution skips adjacent blocks that have a crop above them
- Moisture visible-state threshold is `MoistVisibleThreshold` (0.1) — matches vanilla `IsVisiblyMoist`
- `Initialise()` must run after `SetBlock()` — the block entity resets on placement
- Slow-release nutrients capped at `SlowReleaseMax`; result nutrients capped at `Max`

**State:** `Stored: SupportCode, SupportRetentionDays, SupportFertilityCode, CropGrowth tree — Derived: moistureCode, fertilityCode, growthRate — Persisted: on save/load`

## Implementation

### BlockEntityPlowland
Inherits `BlockEntitySoilNutrition`. Owns support tracking, crop hosting (delegated to `_crop`), and distributed nutrient drain. Implements `IFarmlandBlockEntity`, `IWaterable`, `ICropland`, `IAnimalFoodSource`.

```
// #region Farmland parity — base virtuals CropGrowth cannot reach
RainHeightOffset  => _crop.HasCrop ? 1 : 0    // crop raises rain catch height; else furrow stops catching rain
RecoverFertility  => !_crop.HasRipeCrop       // no NPK recovery under a ripe crop
onRollback()      => base + _crop.OnRollback  // adjust crop schedule on calendar rollback
```

```
// #region interfaces — pass-throughs; delegate to _crop / vanilla base
Water()                  — WaterFarmland(dt, false) + MarkDirty
TryPlant()               — GetGrowthRate → _crop.TryPlant → MarkDirty
GetDrops()               — _crop.GetDrops
IsSuitableFor()          — diet matches crop foodTags
ConsumeOnePortion()      — replace crop with deadcrop(Eaten)

// #region StoredState
// SupportCode, SupportRetentionDays, SupportFertilityCode

// #region Lifecycle

Initialize()
  #region base + _crop.Init(Pos) / _crop.SetRules(growthRateMul)
  #region if(server) POIRegistry.AddPOI(this)

OnBlockPlaced()
  #region base + Initialise(fertility[], moisture=0)

Initialise(initNutrients[], moisture01)
  // Intent: first placement (OnBlockPlaced) and re-plow (ItemPlow.DoPlow)
  #region originalFertility[] = (int)FertilitySet.Value(Block)
  #region clamp nutrients[] to [0, Settings.Max]; clamp moistureLevel to [0, 1]
  #region UpdateSupport() — must precede tryUpdateMoistureLevel, sets totalHoursWaterRetention
  #region tryUpdateMoistureLevel(now, true) + UpdateFarmlandBlock + MarkDirty

beginIntervalledUpdate(out onInterval, out onEnd)
  // Intent: wrap vanilla delegates so base moisture/nutrition runs between UpdateSupport and crop tick
  #region wrap onInterval → UpdateSupport → base → _crop.CheckDamage → TickCrop
  #region wrap onEnd → delegate baseEnd

AddSlowRelease(n, p, k)
  #region slowReleaseNutrients[] += npk, capped at Settings.SlowReleaseMax + MarkDirty

UpdateSupport() → bool
  // Intent: resolve support block each tick; drives totalHoursWaterRetention from support fertility
  #region if(!soil support) { if(no support tracked) return false; ResetSupport; return true }
  #region if(SupportCode + SupportFertilityCode unchanged) return false
  #region SupportCode/FertilityCode = new; SupportRetentionDays = DefaultRetentionDays * (fertility/100)
  #region totalHoursWaterRetention = HoursPerDay * Max(MinRetentionDays, SupportRetentionDays)

ResetSupport()
  #region SupportCode/FertilityCode = null; SupportRetentionDays = 0
  #region totalHoursWaterRetention = HoursPerDay * MinRetentionDays

TickCrop(hourInterval, conds, lightFactor, growthPaused)
  // Intent: growthRate carries no light factor — _crop applies light per interval (native model)
  #region growthRate = cropBlock?.CropProps ? GetGrowthRate(RequiredNutrient) : 1f
  #region if(!_crop.Tick(totalHoursLastUpdate, ..., previousHourInterval, conds, ..., out consumed*)) return
  #region if(consumedAmount > 0) ConsumeNutrientsDistributed(consumedNutrient, consumedAmount)

ConsumeNutrientsDistributed(nutrient, amount, loadQty=2, diagonal=false)
  // Intent: proportional NPK drain — this block + top-N adjacent uncropped soil share the cost
  #region loadBESN = GetBESN(checkCoords).Where(!Crop).SortDesc(nutrient)[:loadQty]
  #region if(nutrientTotal <= 0) return
  #region foreach(loadBESN + this) ConsumeNutrients(amount * share/nutrientTotal)

UpdateFarmlandBlock()
  // Intent: exchange block variant to match current moisture/fertility without destroying entity
  #region if(!Block.Code || !fertilityCode || !sideCode) return
  #region moistureCode = moistureLevel > 0.1 ? "moist" : "dry"
  #region newCode = plowland-{side}-{moist}-{fertility}; if(!resolves || unchanged) return
  #region ExchangeBlock(newBlock, Pos) + MarkBlockDirty + MarkDirty

GetBlockInfo()   — base + Support / Retention / Crop / Stage lines
ToTreeAttributes / FromTreeAttributes — base + _crop tree + support fields (retention rebuilt on load)
```

### ItemPlow
Converts soil or existing plowland/farmland to plowland. Resolves fertility step and nutrient transfer on use.

```
CanPlow(ref pos, out block) — target, else block below if target is air/plant
CanPlow(block) → bool        — static; BlockPlowland/BlockFarmland, or soil with a fertility code

OnLoaded()
  #region if(!client) return
  #region cache plowInteractions from all CanPlow blocks

// #region OnHeldInteract

GetHeldInteractionHelp()     — cached plow interactions + base
OnHeldInteractStart()
  #region if(null / !firstEvent / shift+ctrl) base + return
  #region if(!CanPlow(ref targetPos)) return
  #region apply walkspeed penalty; lastplowx = MinValue; PreventDefault

OnHeldInteractStep()
  #region if(null / shift+ctrl) return false
  #region if(!CanPlow(ref targetPos)) return false
  #region if(server && secondsUsed > PlowSecondsRequired && targetPos != lastplow) { lastplow = targetPos; DoPlow() }
  #region return true

OnHeldInteractCancel / OnHeldInteractStop — remove walkspeed penalty + base

DoPlow(slot, byEntity, blockSel)
  #region if(!CanPlow(ref targetPos, out targetBlock)) return
  #region supportBlock = RevertSupportToSoil(world, supportPos)
  #region ResolveCurrentNutrients(targetBlock / supportBlock); if(!targetFertilityCode) return
  #region chanceChange = avg(targetNPK, supportMax)
  #region underfed: if(randChange > chanceChange) richerBlock.fertility--
  #region overfed:  if(randChange < chanceChange-Neutral) poorerBlock.fertility++
  #region plowlandBlock = GetBlock("plowland-{side}-{moist}-{fertility}"); if(!resolves) return
  #region if(supportFertilityChange) ExchangeBlock(steppedSupport, supportPos)
  #region SetBlock(plowlandBlock, targetPos); bePlowland.Initialise(targetNPK + supportMax, moisture)
  #region AddSlowRelease(ResolveBonusNutrients(...))
  #region ExchangeAdjacentPlowland([left, right]) — revert perpendicular neighbours to farmland
  #region if(byPlayer) slot.DamageItem() + toolbreak sound if empty
  #region PlaySoundAt(targetBlock.Sounds?.Place) + MarkBlockDirty(support, target)

ResolveBonusNutrients(world, targetPos, targetBlock) → float[]
  #region if(weed above) slowFertility[N]++ + clear weed
  #region if(grass-covered soil) slowFertility[N]++
  #region if(blockAbove.CropProps) slowFertility[RequiredNutrient] += fertMax - stagesRemaining
  #region return FertilitySet.Value(slowFertility[]) per axis

TryExchangePlowlandToFarmland(world, pos)
  #region if(!BlockPlowland || crop above || !fertilityCode) return
  #region prevData = beSrc.ToTreeAttributes() — capture NPK + moisture before replacement
  #region farmlandBlock = GetBlock("farmland-{moist}-{fertility}"); if(!resolves) return
  #region SetBlock(farmland); beDst.OnCreatedFromSoil(block, prevData) — restore NPK + moisture
```

### PlowlandSettings
Tuning constants only. No behaviour.

```
StateDry / StateMoist           — block variant moisture key strings
MoistVisibleThreshold = 0.10f   — matches vanilla IsVisiblyMoist
DefaultRetentionDays = 4f       — scaled by support fertility to set totalHoursWaterRetention
MinRetentionDays = 0.25f        — floor applied in UpdateSupport and FromTreeAttributes
Max = 150f                      — result-nutrient cap in DoPlow / Initialise
SlowReleaseMax = 150f           — slow-release ceiling in AddSlowRelease (matches vanilla)
FertilityNeutral = 100f         — avg-nutrient pivot: below loses a tier, above gains a tier
PlowSecondsRequired = 0.6f      — hold time before a drag-plow fires
PlowWalkSpeedPenalty = -0.4f    — walkspeed stat applied while plowing
```

### CropGrowth  *(_Environment/CropGrowth.cs — delegated from BlockEntityPlowland via `_crop`)*
Portable crop layer mirroring `BlockEntityFarmland`'s crop logic so a non-Farmland host catches the same growth, light, damage, **death**, and persistence lifecycles. Self-contained except the three base virtuals the host wires (above). Shared with other farming features.

```

GetCrop(world) → Block? (null-safe before Init) / HasCrop / GetCropStage / HasRipeCrop / CanPlant
TryPlant(block, slot, byEntity, blockSel, world, growthRate) → bool
OnCropBlockBroken() / OnRollback(hours)

Tick(currentTotalHours, hourInterval, previousHourInterval, lightGrowthSpeedFactor,
     moisture01, paused, conds, world, host, growthRate, out consumedNutrient, out consumedAmount) → bool
  #region UpdateCropDamage(conds, hourInterval) — may kill crop
  #region if(!crop) return false
  #region TotalHoursForNextStage += hourInterval*(1-light)   // native light model
  #region if(paused) += previousHourInterval; return true
  #region if(moisture<0.1 || not due yet) return false
  #region grow: stage guard → CropBehaviors → Set/ExchangeBlock → consume nutrient

UpdateCropDamage(conds, hourInterval, world)
  // Intent: own cold/hot stress-hours (not persisted, resets on reload like vanilla damageAccum)
  #region if(!crop) clear flags + accumulators; return
  #region cold: ripe→flag; unripe→flag + accumulate; else decay /10
  #region hot: flag + accumulate; else decay /10
  #region if(!AllowCropDeath) zero accumulators; return
  #region if(accum > 48h) KillCrop(TooCold/TooHot)

KillCrop(world, crop, reason) — SetBlock deadcrop + itemstack + deathReason
GetDrops(drops[], world, blockAttrs) → ItemStack[]   — cold/heat/eaten drop multipliers
GetHoursForNextStage(cropBlock, world, growthRate) → double   // no light factor here
ToTreeAttributes / FromTreeAttributes   — schedule, growthRateMul, 3 damage flags, cropAttrs
```

## Farmland parity

`CropGrowth` + `BlockEntityPlowland` now reproduce `BlockEntityFarmland`'s crop logic: crop death (cold/hot stress accumulation → `deadcrop`), the native per-interval light model, `RainHeightOffset`/`RecoverFertility` overrides, `onRollback` schedule adjustment, `cropAttrs` persistence, and the growth-speed/damage block-info lines. The goal is that `CropGrowth` could host crops on any `BlockEntitySoilNutrition` subclass without depending on native Farmland.

## Open Issues

- **Salt-induced crop death not bridged.** Native kills crops when *any* `damageAccum` index (including `Salt`) passes 48h; `CropGrowth` owns only cold/hot (the climate stresses it can compute from `conds`). Salt accumulation lives in the base `BlockEntitySoilNutrition` water logic, so a Plowland crop will not die from prolonged saltwater proximity. Bridge via the base `damageAccum[Salt]` if salt-death parity is wanted.
- `FertilitySet.StepCode` returning null in `DoPlow` silently keeps the old fertility code — no log, no signal at the boundary.
- Shared `FertilitySet` (and vanilla base) treat `100f` as the fertility/nutrient pivot; `PlowlandSettings.FertilityNeutral` names it only for `ItemPlow`. The two stay in sync by convention, not by reference.
- `BlockEntityPlowland.OnBlockPlaced → Initialise` assumes `Api` is already set (Initialize ran first) — standard VS order, but unguarded.
