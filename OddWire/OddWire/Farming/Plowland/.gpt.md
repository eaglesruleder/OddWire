# Doc — Plowland

**Scope:** Feature
**Domain:** OddWire.Farming
**Status:** Active

---

## Summary

**Goal:** Converts soil into high-retention farmland that sustains moisture and NPK long enough to complete more harvests per season — yield advantage comes from faster crop cycling, not increased drops.

**Lifecycle:**
1. Plow soil — `ItemPlow` converts target block to `plowland-{side}-{moist}-{fertility}`
2. Nutrients transfer — plowland inherits target nutrients + support block max on creation
3. Fertility may shift — repeated plowing steps tier up/down based on avg nutrients vs 100 threshold
4. Crops grow — vanilla `GetGrowthRate` combines NPK + moisture into growth multiplier each tick
5. NPK drains — crop stage advancement pulls nutrients, distributed proportionally across adjacent unfropped soil
6. Moisture decays — rate driven by `totalHoursWaterRetention`, which is set from support block fertility
7. Re-plow — `Initialise()` resets nutrients and moisture in place without destroying crop data

**Rules:**
- `UpdateSupport()` must precede the vanilla base interval — it sets `totalHoursWaterRetention` before moisture logic runs
- `DoPlow` aborts if `targetFertilityCode` is null — block must resolve or no placement occurs
- Nutrient distribution skips adjacent blocks that have a crop above them
- Moisture visible-state threshold is 0.1f — matches vanilla `IsVisiblyMoist`
- `Initialise()` must be called after `SetBlock()` — block entity resets on placement

**State:** `Stored: SupportCode, SupportRetentionDays, SupportFertilityCode, CropGrowth tree — Derived: moistureCode, fertilityCode, growthRate — Persisted: on save/load`

## Implementation

### BlockEntityPlowland
Inherits `BlockEntitySoilNutrition`. Owns support tracking, crop hosting, and distributed nutrient drain.

```
// #region IFarmlandBlockEntity / IWaterable / ICropland / IAnimalFoodSource
// — interface pass-throughs; delegate to _crop and vanilla base

// #region StoredState
// SupportCode, SupportRetentionDays, SupportFertilityCode

// #region Lifecycle

Initialize()
  #region _crop.Init(Pos) / _crop.SetRules(growthRateMul)
  #region if(server) POIRegistry.AddPOI(this)

OnBlockPlaced()
  #region base.OnBlockPlaced + Initialise(fertility[], moisture=0)

Initialise(initNutrients[], moisture01)
  // Intent: called on first placement (via OnBlockPlaced) and on re-plow (via ItemPlow.DoPlow)
  #region originalFertility[] = FertilitySet.Value(Block)
  #region clamp nutrients[] to [0, Settings.Max]; clamp moistureLevel to [0, 1]
  #region UpdateSupport() — must precede tryUpdateMoistureLevel, sets totalHoursWaterRetention
  #region tryUpdateMoistureLevel / UpdateFarmlandBlock / MarkDirty

beginIntervalledUpdate()
  // Intent: wraps vanilla delegates so base moisture/nutrition logic runs between UpdateSupport and crop tick
  #region base.beginIntervalledUpdate(out onInterval, out onEnd)
  #region wrap onInterval → UpdateSupport → base → CheckDamage → TickCrop
  #region wrap onEnd → delegate baseEnd

UpdateSupport() → bool
  // Intent: resolves support block each tick; drives totalHoursWaterRetention from support fertility
  #region if(!block || !soil) ResetSupport + return changed
  #region if(SupportCode + SupportFertilityCode unchanged) return false
  #region SupportCode = newCode; SupportRetentionDays = DefaultRetentionDays * (fertility/100)
  #region totalHoursWaterRetention = HoursPerDay * Max(MinRetentionDays, SupportRetentionDays)

ResetSupport()
  #region SupportCode/FertilityCode = null; SupportRetentionDays = 0
  #region totalHoursWaterRetention = HoursPerDay * MinRetentionDays

TickCrop(hourInterval, lightFactor, growthPaused)
  #region if(!cropBlock || !CropProps) return
  #region growthRate = GetGrowthRate(RequiredNutrient) * lightFactor
  #region if(!_crop.Tick(..., out consumedNutrient, out consumedAmount)) return
  #region ConsumeNutrientsDistributed(consumedNutrient, consumedAmount)

ConsumeNutrientsDistributed(nutrient, amount, loadQty=2, diagonal=false)
  // Intent: proportional NPK drain — this block and top-N adjacent unfropped soil share the cost
  // Intent: insertion sort descending by nutrient level, capped at loadQty
  #region loadBlocks = GetBESN(checkCoords).Where(!Crop).Sort(desc nutrient)[:loadQty]
  #region if(nutrientTotal <= 0) zero + UpdateFarmlandBlock + return
  #region foreach(loadBESN + this) Nutrients -= amount * (Nutrients / nutrientTotal)
  #region UpdateFarmlandBlock + MarkDirty

UpdateFarmlandBlock()
  // Intent: exchanges block variant to match current moisture/fertility without destroying entity
  #region if(!Block.Code || !fertilityCode || !sideCode) return
  #region moistureCode = moistureLevel > 0.1f ? "moist" : "dry"
  #region newCode = plowland-{side}-{moist}-{fertility}; if(!changed || !resolves) return
  #region ExchangeBlock(newBlock, Pos) + MarkBlockDirty
```

### ItemPlow
Converts soil or existing plowland to plowland. Resolves fertility step and nutrient transfer on use.

```
CanPlow(block) → bool
  // static; true for BlockPlowland, BlockFarmland, or any soil block with a fertility code

OnLoaded()
  #region if(!client) return
  #region cache plowInteractions from all CanPlow blocks

// #region OnHeldInteract

OnHeldInteractStart()
  #region if(null / !firstEvent / shift+ctrl) base
  #region if(covered) TriggerIngameError("Requires no block above") + PreventDefault
  #region if(!CanPlow) return; set didplow=0 + PreventDefault

OnHeldInteractStep()
  #region if(null / shift+ctrl) return false
  #region if(covered || !CanPlow(targetBlock)) return false
  #region if(server && secondsUsed > 0.6f && targetPos != lastplowPos) DoPlow(); lastplowPos = targetPos
  #region return true

DoPlow(slot, byEntity, blockSel)
  #region if(!CanPlow(targetBlock)) return
  #region supportBlock = world.GetBlock(supportPos); RevertSupportToSoil
  #region targetFertilityCode = GetCode(targetBlock); if(null) return
  #region targetNutrients = ResolveNutrients(targetBlock / targetBlockEntity)
  #region Lose fertility when underfed (avgNutrients < 100)
  #region Gain fertility when overfed (avgNutrients > 100)
  #region plowlandBlock = GetBlock("plowland-{side}-{moist}-{fertility}"); if(null) return
  #region if(supportFertilityChange) ExchangeBlock(nextSupportBlock, supportPos)
  #region SetBlock(plowlandBlock, targetPos)
  #region bePlowland.Initialise(targetNutrients + supportMax, targetMoisture01)
  #region if(byPlayer) slot.DamageItem()
  #region PlaySoundAt(targetBlock.Sounds.Place) + MarkBlockDirty
```

### PlowlandSettings
Tuning constants only. No behaviour.

```
StateDry / StateMoist           — block variant moisture key strings
MoistVisibleThreshold = 0.10f  — matches vanilla IsVisiblyMoist
DefaultRetentionDays = 4f      — scaled by support fertility to set totalHoursWaterRetention
MinRetentionDays = 0.25f       — floor applied in UpdateSupport and FromTreeAttributes
Max = 150f                     — nutrient cap applied in Initialise result nutrients
```
