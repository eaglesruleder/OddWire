## Summary

**Goal:** Domain roll-up — a tick-driven composting block plus the watering-can patch that feeds it through the shared `IWaterable` contract. This doc lists each feature's classes and methods at one altitude up; the full region-level pseudocode lives in each feature's own `.gpt.md`.

**Features:** CompostPile (block + block entity + settings), Plowland (plow item + soil-nutrition block entity + settings), WateringCan Patch (Harmony postfix + `IWaterable`).

**Registration:** `OddWireFarming` ModSystem registers `BlockCompostpile` and `BlockEntityCompostpile`.

## CompostPile
Full region detail: [CompostPile/.gpt.md](CompostPile/.gpt.md) · Gameplay brief: [CompostPile/.git.md](CompostPile/.git.md)

### BlockCompostpile
Handles player interaction, neighbour notifications, and break/harvest routing.

```
OnLoaded()                          — build + cache interaction-help entries (Turn / Add / Boost)
GetPlacedBlockInteractionHelp()     — append cached interactions to base help
OnBlockInteractStart()              — route held stack into be.TryAdd; consume on accept (server)
OnHeldInteractStart()               — consume held input into target pile before default placement
OnNeighbourBlockChange()            — flag be.NeighboursDirty (server)
OnBlockBroken()                     — be.Harvest; keep block if still harvestable, else base break
```

### CompostpileSettings
Static tuning data only — no runtime logic. Single shared `Default` instance read by both block classes. Per-ingredient quantities, conversion ratios, harvest yields, per-food-category nutrition tuning. Regions: IngredientTuning, CompostRate, Moisture, Aeration, Temperature, Harvest, BlockInfo.

## Plowland
Full region detail: [Plowland/.gpt.md](Plowland/.gpt.md) · Gameplay brief: [Plowland/.git.md](Plowland/.git.md)

### BlockEntityPlowland
Inherits `BlockEntitySoilNutrition`. Owns support tracking, moisture-retention wiring, crop hosting (via `CropGrowth`), distributed NPK drain across adjacent uncropped soil, block-variant updates, and persistence.

```
Initialise()                 — clamp NPK/moisture, UpdateSupport before tryUpdateMoistureLevel
UpdateSupport()              — resolve soil below → totalHoursWaterRetention from support fertility
beginIntervalledUpdate()     — wrap vanilla onInterval: UpdateSupport → base → CheckDamage → TickCrop
TickCrop()                   — GetGrowthRate → _crop.Tick → ConsumeNutrientsDistributed
ConsumeNutrientsDistributed()— this block + top-N richest uncropped neighbours share the drain
UpdateFarmlandBlock()        — exchange to plowland-{side}-{moist}-{fertility} without resetting entity
AddSlowRelease()             — top up slow-release nutrients (capped)
```

### BlockPlowland
Solid-face / crop-attachment rules; routes interact to `be.OnBlockInteract` (vanilla fertilizer hook), server only.

### ItemPlow
Plow tool. Drag-plows on hold; `DoPlow` resolves the target, rolls a fertility step, transfers target+support nutrients, places the furrow, reverts perpendicular neighbours to farmland, and spends durability.

### PlowlandSettings
Tuning constants only — retention days, nutrient caps, fertility pivot, plow timing/walkspeed.

### CropGrowth / FertilitySet
Shared `_Environment/` helpers: `CropGrowth` holds crop state + per-tick growth/damage/drops; `FertilitySet` resolves fertility codes/values/steps and the support-revert roll.

## WateringCan Patch
Full detail: [_Patches/WateringCan/.gpt.md](_Patches/WateringCan/.gpt.md)

### BlockWateringCan_OnHeldInteractStep_IWaterable_Patch
Harmony postfix on `BlockWateringCan.OnHeldInteractStep` — captures elapsed `dt` from the `secondsUsed` delta (prefix stashes pre-step value in `__state`), skips refill ticks, resolves the target block position through empty/fluid layers, and dispatches `Water(dt)` to it when it implements `IWaterable` (server only, positive dt only).

### IWaterable
Domain contract — `Water(dt)` accepts elapsed watering time. Implemented by `BlockEntityCompostpile`.
